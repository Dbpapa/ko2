# My Telegram Bot

This is a simple Telegram bot built with Python using the `python-telegram-bot` library.

## Features

- Responds to the `/start` command with a welcome message.
  
## Deployment

This bot can be deployed using Docker on platforms such as Koyeb, Heroku, or any cloud platform that supports Docker.

## To deploy on Koyeb:

1. Clone this repository or push it to your GitHub.
2. Create a new app on Koyeb.
3. Link the app to your GitHub repository.
4. Set your environment variables (like `TOKEN`) on Koyeb.
5. Deploy the app.
